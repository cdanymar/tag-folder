# Tag Folder

The main PowerShell scripts lets users edit some desktop.ini attributes for Windows file
explorer folders.

The batch (.bat) files are to install and uninstall that script to right classic context
menu.

## Installation

Run `install.bat`.

## Usage

1. Right-click (while holding Ctrl) a folder.
2. Select 'Tag Folder' option.
3. Enter your tag.
4. Click OK.
